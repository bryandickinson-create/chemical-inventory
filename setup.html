Setting up the Inventory app

What to enter on each new phone, tablet, or computer

i What you'll need

Every device needs the same two values so it talks to the same shared database. A third value is optional and personal to each device.

Firebase Config Same for everyone

Points the app at your lab's shared database.

Lab Key Same for everyone

A shared password. Devices with different keys see different, separate inventories.

Gemini API Key Per device · optional

Powers "Snap Label". Without it, everything else still works.

Don't know your Firebase Config or Lab Key? Section 1 below shows how to read them off a device that's already working.

1 Find your existing settings

Do this on a device where the app already works — one that shows your real inventory.

  1. Open the app and tap the gear icon ⚙ in the top-right.
  2. Under Firebase Config, the box already contains your value. Select it all and copy it.
  3. Under Lab Key, tap Show to unmask it, then write it down or copy it.
  4. Close Settings.

The Gemini key can also be revealed with Show, but each person can just as easily use their own free key — see section 4.

If no device works yet

Then the database hasn't been created, or nobody has the key. See section 6 for starting from scratch.

Keep these off the internet. Don't put the Lab Key or Firebase Config in a public document, a GitHub repo, or a shared web page. Anyone who has both can read and change your inventory. Send them to labmates directly — in person, or over a message you trust.

2 Set up the new device

  1. Open the app link in the device's browser.
    On iPhone/iPad this must be Safari. On Android, use Chrome.
  2. Tap the gear icon ⚙ in the top-right.
  3. Paste your Firebase Config into the first box and tap Save.
  4. Type your Lab Key into the second box and tap Save.
    It must match the other devices exactly — capital letters and spaces count.
  5. Close Settings and reload the page. Both settings only take effect after a reload.

You should briefly see "Connected to shared database." at the bottom of the screen.

Check it worked

Tap Inventory. The number badge next to the word "Inventory" should match what you see on your other devices.

Badge shows 0, or the list is empty? Almost always a mistyped Lab Key. A different key isn't an error — it opens a brand-new empty inventory. Go back to Settings, tap Show under Lab Key, and compare it character by character with your working device.

3 Add it to the home screen

This makes it open like a real app — full screen, its own icon, and it works with no signal.

iPhone / iPad

  1. In Safari, tap the Share button (the square with an arrow).
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add.

Android

  1. In Chrome, tap the ⋮ menu.
  2. Tap Install app or Add to Home screen.

Desktop (Chrome or Edge)

  1. Click the install icon in the address bar, or the ⋮ menu → Install.
Do the settings from section 2 before adding to the home screen, so the installed app starts out already connected.

4 Optional: Snap Label (AI)

Lets you photograph a bottle label and have the fields filled in automatically. It's free for normal lab use, and each person can have their own key.

  1. Go to aistudio.google.com/apikey and sign in with a Google account.
  2. Click Create API key and copy it.
  3. In the app: gear icon ⚙ → Google Gemini API Key → paste → Save.

Skip this and everything else still works — you just type entries in by hand, and the manual lookup falls back to PubChem.

5 Last step: pick your name

At the top of the app there are two dropdowns. These decide who gets credited for each bottle.

  • Name — pick yourself. If you're not listed, tap Edit next to it and add yourself.
  • Location — where you're currently working. Tap Edit to add shelves, cabinets, or rooms.

Both lists are shared with the whole lab, so anything you add here shows up for everyone. Your own selections are remembered on this device.

6 Starting a brand-new lab database

Only needed once, by whoever sets the lab up. Skip this if a database already exists.

  1. Go to console.firebase.google.com and create a project (the free Spark plan is enough).
  2. In the left sidebar choose Build → Realtime Database, then Create Database.
  3. Copy the database URL — it looks like: 
    https://your-project-default-rtdb.firebaseio.com
  4. Paste that into Firebase Config in the app's Settings.
  5. Invent a Lab Key — a shared password for the lab. Anything memorable works, but longer is better. Everyone will type this exact string.
  6. Reload, then hand both values to your labmates using section 2.
A note on security. The Lab Key is scrambled into a folder name inside the database — it keeps casual snooping out, but it is not real protection. Anyone who knows the database URL could still reach the data. If your inventory is sensitive, set proper Firebase security rules on the database, which is the real fix.

? Troubleshooting

"Offline" appears in the top-left

The app can't reach the database. It still works — everything you do is saved on the device and uploads automatically once you're back on Wi-Fi. Nothing is lost.

A number like "3 unsynced" appears

Three changes are waiting to upload. Open the app somewhere with signal and leave it open a few seconds; the badge disappears once they've gone up. Don't clear your browser data while this is showing — that would discard those changes.

The inventory is empty on a new device

Nearly always a mistyped Lab Key — see the box in section 2.

Two devices show different inventories

Their Lab Keys don't match. Reveal both with Show and compare exactly.

The app looks out of date after an update

Close it completely and reopen it. Because it's built to work offline, it may serve the previous version once before picking up the new one.

Snap Label says no API key

That key is per-device — see section 4. Every new device needs its own.

Starting over on a device

Clear the site's data in browser settings, then redo section 2. Only do this when nothing shows as unsynced.
